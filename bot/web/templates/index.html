متجر Telegram — لوحة الإدارة

مرجع سريع للوحة الإدارة. تُسجّل كل عمليات الإضافة والتعديل والحذف في سجل التدقيق، وتُحدّث ذاكرة التخزين المؤقت للبوت تلقائيًا بعد كل تغيير.

📦 بيع المنتجات (المنتج + المخزون)

المنتج هو العرض (الاسم والسعر والوصف والتصنيف والخصم الاختياري)، وتُحفظ وحداته القابلة للبيع منفصلة كـ عناصر مخزون.

  1. أنشئ تصنيفًا عند الحاجة.
  2. أنشئ منتجًا وحدد الاسم والسعر والوصف والتصنيف، والخصم اختياري.
  3. أضف عناصر مخزون للمنتج، وهي ما يستلمه المشترون فعليًا.

حقول عنصر المخزون:

  • item — المنتج الذي تنتمي إليه هذه الوحدة.
  • value — المحتوى المُسلّم (حساب أو مفتاح أو نص ترخيص...).
  • is_infinity — off: وحدة محدودة تُستهلك عند الشراء؛ on: غير محدودة ويُسلّم نفس value في كل عملية شراء.

تحافظ إعادة تسمية المنتج أو حذفه تلقائيًا على اتساق السلال والتقييمات وسجل المشتريات.

🔐 الأدوار والصلاحيات

قيمة permissions للدور هي bitmask: اجمع قيم الصلاحيات المطلوبة. الأدوار المضمنة: USER (1)، ADMIN، OWNER (كل القيم). لا يمكنك منح صلاحيات لا تملكها.

الصلاحيةالقيمةتمنح
USE1الوصول الأساسي للبوت
BROADCAST2المراسلة الجماعية
SETTINGS4وضع الصيانة
USERS8عرض/حظر المستخدمين والإحالات والمشتريات
CATALOG16التصنيفات والمنتجات والمخزون
ADMINS32إنشاء الأدوار وتعيينها
OWNER64عمليات المالك فقط
STATS128الإحصاءات والسجلات والبحث عن العناصر
BALANCE256شحن/خصم الرصيد
PROMO512إدارة الأكواد الترويجية

Example: a catalog manager who also sees stats = USE + CATALOG + STATS = 1 + 16 + 128 = 145. Prefer the bot's role menu for a click-to-toggle UI.

🧭 وظيفة كل قسم

  • Users — balance, role, block status (edits take effect immediately).
  • Roles — permission bitmasks (see the table).
  • Categories / Products / Stock Items — the catalog.
  • Promo Codes — percent / fixed / balance codes, limits, expiry.
  • Purchases / Payments / Operations — read-only financial history.
  • Reviews — 1–5★ product reviews.
  • Audit Logs — read-only record of every admin action.

💡 معلومات مهمة

  • Financial tables (purchases, payments, operations) and audit logs are read-only by design.
  • Prices/balances use exact decimals — enter plain numbers (e.g. 199.99).
  • A promo code's discount_type is one of percent, fixed, or balance.
  • Most day-to-day tasks are also available in the bot's in-chat admin menu, which is often quicker for catalog and role edits.
